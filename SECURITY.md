# Security policy

## Supported versions

Security fixes are released for the latest version of the SDK. Clients should
upgrade to the newest tagged release before reporting an issue.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
[support@bypass.fast](mailto:support@bypass.fast). Do not open a public issue.

Include the affected SDK version, a minimal reproduction, and the potential
impact. Do not include live API keys, solver payloads, cookies, tokens, device
fingerprints, or proxy credentials. We will acknowledge the report and
coordinate remediation and disclosure through email.
